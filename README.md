# ⚡ WireGuard VPN Manager Classic

**Быстрый · Современный · Безопасный**

Интерактивный Bash-скрипт для установки и управления WireGuard VPN-сервером.  
Никаких зависимостей, никаких GUI — только чистый терминал и красивое меню.

</div>

| Функция | Описание |

| 🚀 **Автоустановка** | Мастер настройки из 8 шагов с умными дефолтами |

## 📦 Установка

### Быстрый старт

```bash
curl -O https://raw.githubusercontent.com/avar-soft/wireguard-classic/main/wireguard-classic.sh
chmod +x wireguard-classic.sh
sudo bash wireguard-classic.sh
```

### Или через git

```bash
git clone https://github.com/avar-soft/wireguard-classic.git
cd wireguard-classic
sudo bash wireguard-classic.sh
```

> ⚠️ Скрипт должен запускаться **с правами root**. На первом запуске автоматически стартует мастер установки.

---

## 🔧 Мастер установки (8 шагов)

При первом запуске скрипт проведёт через настройку сервера:

```
[1/8]  Публичный IP сервера         — автоопределяется, можно изменить
[2/8]  Внешний сетевой интерфейс    — eth0 / ens3 / и т.д.
[3/8]  Имя WireGuard-интерфейса     — обычно wg0
[4/8]  IPv4 сервера внутри туннеля  — например 10.66.66.1
[5/8]  UDP-порт                     — случайный из 49152–65535 или свой
[6/8]  IPv6 в туннеле               — опционально
[7/8]  DNS-серверы для клиентов     — Cloudflare, Google или свои
[8/8]  AllowedIPs                   — full-tunnel или split-tunnel
```

После установки автоматически создаётся первый клиент и показывается QR-код.

## 🖼️ Интерфейс

Скрипт использует цветное оформление терминала:

- 🟢 **Зелёный** — создание, успех, подтверждение
- 🟡 **Жёлтый** — предупреждения, удаление клиента
- 🔴 **Красный** — опасные действия (удаление WireGuard)
- 🔵 **Синий / Голубой** — информация, навигация
- ⬛ **Серый** — дополнительные данные, выход

## 🔒 Безопасность

- Все ключи генерируются локально через `wg genkey` / `wg genpsk`
- Конфиги создаются с `umask 077` (права `600`, только root)
- Используется **PresharedKey** для каждого клиента (защита от будущих квантовых атак)
- Ключи **не передаются** никуда и не логируются

## ❓ FAQ

**Q: Можно ли запустить без systemd?**  
A: Да. Alpine Linux поддерживается через OpenRC.

**Q: Сколько клиентов можно создать?**  
A: До 253 в стандартной подсети `/24`.

**Q: Как подключиться с телефона?**  
A: Установите приложение [WireGuard](https://www.wireguard.com/install/) и отсканируйте QR-код из пункта 3 меню.

**Q: Как изменить порт после установки?**  
A: Отредактируйте `ListenPort` в `/etc/wireguard/wg0.conf` и `SERVER_PORT` в `/etc/wireguard/params`, затем перезапустите службу (пункт 7).

**Q: Поддерживается ли IPv6 для подключения клиентов?**  
A: Да — публичный IP сервера может быть IPv6, туннель тоже поддерживает IPv6 (шаг 6/8 мастера).
